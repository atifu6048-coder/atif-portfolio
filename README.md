# 🚀 Atif | Senior Full Stack Developer Portfolio

An ultra-modern, high-performance portfolio website engineered with clean Vanilla HTML5, CSS3 Glassmorphism, and interactive JavaScript. Tailored specifically for a **Full Stack Web Developer** specializing in React, Node.js, Python, and scalable modern web architecture.

---

## 🌟 Key Features

1. **Modern Dark Glassmorphism Aesthetic**:
   - Deep space background (`#070a13`) with subtle glowing ambient cyan (`#00f2fe`) and purple (`#a855f7`) radial mesh orbs.
   - Frosted glass cards with `backdrop-filter: blur(20px)` and subtle glowing borders.

2. **Interactive Constellation & Particle Canvas**:
   - Interactive HTML5 canvas with connected nodes that gently react to mouse movement.

3. **Dynamic Multi-phrase Typewriter**:
   - Smooth typewriter effect cycling through roles: *Full Stack Web Developer*, *MERN Stack Specialist*, *Node.js & Python Engineer*, *High-Performance UI Architect*.

4. **Interactive Projects Showcase (Requested Feature)**:
   - Dynamic category filter buttons: `All`, `Full Stack`, `AI & SaaS`, `E-Commerce`, `DevOps & Cloud`.
   - **Interactive Modal Case Study**: Clicking on any project opens a full modal showcasing high-resolution project images, architecture overview, key technical achievements, and live demo / source code buttons.

5. **Skills & Tech Stack Matrix**:
   - Organized into Frontend, Backend, Databases, and Cloud DevOps.
   - Animated skill proficiency progress bars that trigger when scrolled into view.

6. **Animated Number Counters**:
   - Interactive counters for Years of Experience, Completed Projects, Enterprise Clients, and Lines of Code.

7. **Dual-Column Career Journey**:
   - Beautiful glowing vertical timeline tracking Work Experience and Academic Degrees / Certifications.

8. **Interactive CV / Resume Modal**:
   - In-app resume viewer with a one-click **"Print / Save PDF"** button.

9. **Interactive Contact Form & WhatsApp Integration**:
   - Contact form with real-time feedback, simulated sending spinner, and animated toast notification.
   - Direct WhatsApp one-click chat button (`+92 300 1234567`).

## ⚡ How to Run Locally

### Option 1: Direct File Open
Simply double-click [`index.html`](file:///d:/atif%20portfolio/index.html) to open directly in any modern browser (Chrome, Edge, Firefox, Brave).

### Option 2: Run via Node.js
If you have Node.js installed, open terminal in this folder and run:
```bash
npx serve .
```
Or open: `http://localhost:5173`

## 🌐 How to Deploy for Free

- **GitHub Pages**: Push this repository to GitHub, go to `Settings > Pages`, and select `main` branch.
- **Vercel / Netlify**: Simply drag and drop the `atif portfolio` folder to [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com) for instant live HTTPS deployment!
